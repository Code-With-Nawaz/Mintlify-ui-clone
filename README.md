# Mintlify UI Clone

A desktop-first documentation-style website recreated based on the Mintlify website.

This project focuses on layout structure, typography, spacing, and visual accuracy using only HTML and CSS.

---

## 🔗 Live Demo

Live Website:  
https://mintlify-ui-clone-by-shahnawaz.vercel.app/

GitHub Repository:  
https://github.com/Code-With-Nawaz/Mintlify-ui-clone

---

## 🛠 Tech Stack

- HTML5
- CSS3
- Desktop-first layout
- No JavaScript
- No frameworks

---

## 📌 Sections Implemented

- Top Navigation Bar
- Hero Section (headline, description, email input, CTA, background)
- Documentation Preview Layout
- Trusted By / Company Logos
- Feature Highlights (two-column layout)
- Intelligent Assistant / UI Preview
- Enterprise Features Section
- Case Studies / Customer Stories
- Final Call-To-Action
- Footer

---

## 🎨 Design Focus

- Matched fonts, colors, and spacing closely to the original design
- Clean grid-based layout
- Proper content alignment and readability
- Structured documentation-style UI
